                Language model

                Context length
                2k32k

                The context is the model's short-term memory: everything it can see at once — the character's description, the rules, its memory (facts and summary) and the recent conversation. About half of it is kept for the conversation itself.

                • When a chat outgrows it, the oldest part is summarized automatically. Nothing breaks; the character just remembers older details only from the summary and the facts.
                • More context means the character remembers more of the conversation word for word, but it needs more GPU memory and long chats take a little longer before each reply starts.
                • Green: fits completely on the GPU (fast). Yellow: part of the model moves to the CPU (noticeably slower). Red: too big.
                • The zones are measured for the loaded model and change with the model, its quantization and whether the microphone and voice output are on.
                • Automatic picks the largest value in the green zone, up to the limit of your hardware profile. Changing the value reloads the model, which takes a few seconds.

                Sets the recommended quantization in the model catalog, how speech recognition runs and how long the automatic context may get. Speech recognition changes after a restart.

                The hardware profile adapts the app to your GPU memory (VRAM). It is detected automatically; you only change it to trade quality for memory, for example when another program needs part of the GPU.

                • Quantization: how finely a language model is stored. Higher numbers (Q6) sound more natural and make fewer mistakes but need more memory; Q4 is smaller and a little less precise. The catalog recommends the one in the table below.
                • Speech recognition: Whisper runs in full precision (float16) on big GPUs and in a compact form (int8) on smaller ones, which saves about 1 GB.
                • Automatic context: the longest context the app chooses by itself.
