              Add your own model

              A Hugging Face repo id (owner/name), a Hugging Face link, or a direct link to a .gguf file. Only the one matching GGUF file is downloaded. GGUF files you copy into models\llm appear here automatically.

              Uncensored "abliterated" / "heretic" models can be slightly less precise than the originals; you are responsible for how you use them. Roleplay finetunes are strongest in English. Each model has its own license, shown with the model.

              Edit character

              Describe who the character is, how they talk, what they know and where the conversation takes place. The model follows this in every conversation with this character. English works best with most models, but German is fine too. Rules for speech (no markdown, no stage directions read aloud) are added automatically.

              Voice output

              More steps and fp32 can sound cleaner but take longer before the reply starts. Synthesis time roughly doubles from 32 to 64 steps; fp32 also needs about 2 GB more VRAM.

              Language model

              How much of the conversation the model sees at once. Longer chats are summarized into the character's memory anyway. A longer context needs more GPU memory; the model is reloaded when you change it.

              Sets the recommended quantization in the model catalog and how speech recognition runs. Speech recognition changes after a restart.
